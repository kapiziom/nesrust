Master palettes (.pal files).

2C02G_U_wiki.pal  - nesdev "2C02G (wiki)" palette with the 8 emphasis variants (1536 bytes = 8 x 64 RGB triplets).
                    It is compiled into the emulator as the default (src/emulator/ppu/palette.rs).
                    Source: https://www.nesdev.org/wiki/PPU_palettes

Other .pal files (192 bytes = 64 RGB triplets, or 1536 bytes with emphasis) can be loaded with Palette::from_pal_bytes.

Provenance of 2C02G_U_wiki.pal (from its nesdev page):
  A palette generated by Pally v0.23.0 with the following arguments:
    pally.py --skip-plot -cld -phd 4 -e -blp 7.5 -o docs/NESDev/2C02G_U_wiki.pal
  RC lowpass time constant chosen to result in approximately -5 degrees of hue shift per color column.
